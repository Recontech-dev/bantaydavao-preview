# BantayDavao web preview

This repository holds the built files of the BantayDavao web preview, served with GitHub Pages:

**https://recontech-dev.github.io/bantaydavao-preview/**

BantayDavao is a free safety app for Davao City by Recontech. It turns heat, rain and flood safety into daily
quests. On a phone, open the link and choose "Add to Home screen" to install it. On a wide screen, the side
panel has presenter controls for the season, the clock and the theme.

This is a preview. The forecast and air quality are live estimates, the rainfall warning level is set by hand,
and hotlines and some places are not yet verified by the City. It is not an official app of the City Government
of Davao, PAGASA or DOH. **In an emergency, call 911.**
